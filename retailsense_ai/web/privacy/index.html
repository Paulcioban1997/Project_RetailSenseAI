Politique de confidentialité

RetailSense AI — Dernière mise à jour : 19 juillet 2026

La présente politique de confidentialité décrit comment l'application RetailSense AI (« l'Application »), éditée par PMC Solutions AI, traite les informations lorsque vous utilisez ses services.

1. Données que nous collectons

RetailSense AI ne collecte aucune donnée personnelle identifiable. L'Application ne demande pas votre nom, votre adresse, ni votre localisation.

Les seules données traitées sont celles que vous saisissez volontairement dans les formulaires de prédiction (par exemple : montants de transactions, textes d'avis clients, valeurs de demande). Ces données sont envoyées à notre API pour générer une prédiction, puis ne sont pas conservées.

2. Utilisation des données

Les données saisies sont utilisées uniquement pour :

  • Générer les résultats de prédiction demandés (demande, prix, sentiment, anomalies, etc.) ;
  • Assurer le bon fonctionnement technique du service.

Aucune donnée n'est vendue, louée ou partagée à des fins publicitaires.

3. Traitement par notre API

Les prédictions sont calculées par une API hébergée sur Render. Les données transmises servent uniquement au calcul en temps réel et ne sont pas stockées de manière permanente.

4. Sécurité

Toutes les communications entre l'Application et notre API sont chiffrées via HTTPS. Nous mettons en œuvre des mesures raisonnables pour protéger les informations traitées.

5. Services tiers

L'Application s'appuie sur des services d'hébergement (Render, Netlify) qui peuvent traiter des données techniques (adresse IP, journaux de requêtes) conformément à leurs propres politiques de confidentialité.

6. Données des enfants

L'Application est destinée à un usage professionnel et n'est pas conçue pour les personnes de moins de 13 ans.

7. Modifications de cette politique

Cette politique peut être mise à jour. Toute modification sera publiée sur cette page avec une date de mise à jour révisée.

8. Contact

Pour toute question relative à cette politique de confidentialité, contactez : contact@retailsenseai.ca
